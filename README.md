# 에셋 생성기

대상 하나를 18가지 스타일로 그려보고, 마음에 드는 스타일로 같은 톤의 에셋 세트를 만드는 사내 도구입니다.
글자 없는 심볼·일러스트만 만듭니다. PNG로 내려받아 앱·웹·배너에 씁니다.

생성에는 **각자 컴퓨터에 로그인된 본인 ChatGPT 구독**이 쓰입니다. API 키는 필요 없습니다.
그래서 서버 한 대를 같이 쓰지 않고, 각자 자기 컴퓨터에서 띄워서 씁니다. 다른 컴퓨터에서 접속하면 거부됩니다.

## 설치 (맥 앱, 권장)

1. `asset-gen-<버전>-arm64.dmg`를 열고 "에셋 생성기"를 응용 프로그램 폴더로 끌어 넣습니다.
2. 처음 열 때 "악성 코드가 없음을 확인할 수 없습니다" 경고가 뜨면 "휴지통으로 이동"이 아니라 "완료"를 누르고, 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"를 누릅니다. 안 되면 터미널에서 `xattr -dr com.apple.quarantine "/Applications/Asset Gen.app"`. 공증 전까지 처음 한 번만 필요합니다.
3. 앱 위쪽 안내에서 "ChatGPT로 로그인"을 누르고 브라우저에서 본인 계정으로 로그인합니다. 끝나면 앱이 자동으로 이어집니다.

필요한 것은 Apple Silicon 맥과 ChatGPT Plus 이상 구독뿐입니다. Node·터미널은 필요 없습니다.
결과 파일은 메뉴 "파일 > 결과 폴더 열기"(`~/Library/Application Support/에셋 생성기/output`)에 있습니다.
앱 안의 코드를 고치면 앱이 실행되지 않습니다(무결성 검사).

## 소스 폴더로 실행하기 (개발·대체 경로)

필요한 것: 맥, 인터넷, ChatGPT Plus 이상 구독. 다른 설치는 필요 없습니다.

1. 압축을 풀고 `asset-gen` 폴더 안의 **시작하기.command**를 더블클릭합니다.
2. 처음에는 필요한 것을 자동으로 준비합니다(3~5분). 중간에 브라우저가 열리면 **본인 ChatGPT 계정으로 로그인**합니다.
3. 준비가 끝나면 브라우저에 에셋 생성기가 열립니다. 다 쓰면 터미널 창을 닫습니다.

두 번째부터는 더블클릭하면 몇 초 안에 열립니다.

**"열 수 없습니다" 경고가 뜨면** (인터넷으로 받은 파일이라 처음 한 번 뜹니다)
시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "시작하기.command" 항목의 **그래도 열기**를 누른 뒤 다시 더블클릭합니다.

준비 중 오류가 나면 터미널 창을 캡처해서 전달해 주세요.

### 터미널에 익숙하다면

Node.js 22.12 이상이 있으면 `npm install` 후 `npm run app`으로도 실행됩니다. 주소는 http://127.0.0.1:1230 입니다.

## 쓰는 법

1. **스타일 탐색**: 무엇을 그릴지 입력하고 스타일을 고릅니다(기본 18개 전체). 스타일마다 한 장씩 만듭니다.
2. **세트 만들기**: 마음에 든 결과에서 "이 스타일로 세트"를 누르면 그 이미지를 참고해 같은 톤으로 여러 대상을 그립니다. 한 줄에 하나씩, 최대 12개.
3. **기록**: 지금까지 만든 에셋을 다시 보고 내려받습니다. 파일은 이 폴더의 `output/`에 저장됩니다.

## 알아둘 점

- 한 장에 수십 초가 걸리고, 기본으로 2장씩 동시에 만듭니다. 장수만큼 구독 사용량을 씁니다. 한도에 닿으면 실패 카드에 안내가 나옵니다.
- 이미지는 Codex 내장 이미지 도구(공식 문서상 GPT Image 2)가 그립니다. 대화 모델은 지정하지 않고 각자 Codex 기본 모델을 씁니다.
- 배경은 깨끗한 밝은 단색으로 요청합니다. 투명 배경은 아직 지원하지 않습니다.
- 같은 스타일이어도 대상마다 색감·질감이 조금씩 달라질 수 있습니다. 세트 모드의 참고 이미지가 이를 줄여줍니다.
- 결과에 글자가 섞이거나 지시와 다른 표현이 나올 수 있습니다. 그럴 땐 "다시 생성"을 누릅니다.

## 설정 (환경변수)

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `ASSET_GEN_PARALLEL` | 2 | 동시 생성 수 (1~4) |
| `ASSET_GEN_OUTPUT` | ./output | 결과 저장 폴더 |
| `ASSET_GEN_FAKE` | | `1`이면 구독을 쓰지 않는 테스트 모드 |

## 개발

```sh
npm run dev      # 개발 서버 (1230)
npm run check    # 포맷·린트·타입 검사
npm run zip      # 소스 압축 파일 만들기 (../asset-gen.zip)
make app         # 맥 앱 만들기 (dist/asset-gen-<버전>-arm64.dmg)
npm test         # 테스트 모드로 브라우저 테스트 (구독 사용 안 함)
```

스타일 정의는 `src/styles.ts`, 생성 지시문은 `src/prompt.ts`, Codex 실행은 `src/server/codex.ts`입니다.
스타일은 logo-gen의 ToothKind 18안(2026-09-15) 지시를 대상과 분리해 일반화한 것입니다.
