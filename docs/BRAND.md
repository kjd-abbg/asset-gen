# 브랜드: 에셋 생성기 로고

절차는 `docs/LOGO_DESIGN.md`. 원본은 `tool/gen-icons.mjs`가 만든다(`node tool/gen-icons.mjs`). 파생 파일을 직접 고치지 않는다.

## 로고 브리프 (2026-10-08)

| 슬롯 | 내용 |
| --- | --- |
| Concept | 대상 하나가 여러 스타일로 갈라져 나온다 |
| Symbol | 같은 견본 세 장이 부채꼴로 펼쳐짐. 16px에서는 부채 윤곽만 남김 |
| Visual metaphors | 색 견본 부채, 스타일 카드, 같은 판의 다른 인쇄 |
| Shape language | 둥근 사각 견본(앱 카드 반경과 같은 결), 굵은 선, 좌우 24° 대칭 펼침, 견본 사이 틈은 투명하게 오림 |
| Composition | 심볼 단독(앱 아이콘·상단 바). 워드마크는 Pretendard로 화면에서 조판 |
| Effects | flat. 뒤 두 장은 테두리·줄무늬, 앞 한 장은 꽉 참 |
| Avoid | AI 반짝임·별, 요술봉, 붓·팔레트, 2×2 격자, 얇은 선, 그림자·광택 |

## 결정 기록 (창작 기여)

- 2026-10-08 첫 아이콘(2×2 타일 + 반짝임)에 대해 결정자: "로고가 좀 구린데".
- 1차 방향 A 견본 부채·B 하나에서 여럿·C 캔버스 밖으로를 그렸고, 에이전트 평가로 A 사원증 연상·B 16px 뭉개짐·C 알림 배지 클리셰를 보고하고 다듬은 2차 A2·B2·D를 제시(`artifacts/design/logo/directions-2.html`).
- 결정자 선택: "견본 부채 좋네 퍼랭이로다가" → A2를 코발트 `#2453d6` 앱 아이콘으로 확정.
- 정제: 소형 변형 분리(줄무늬 제거, 선 30→44), 틈을 흰 칠에서 마스크 오림으로 바꿔 어느 바탕에서도 한 색 유지, viewBox를 렌더 실측 범위로 자름.

## 파일과 용도

| 파일 | 용도 |
| --- | --- |
| `build-resources/icon.svg` → `icon.icns` | 맥 앱 아이콘. 64px 이상은 기본형, 32px 이하는 `icon-small.svg` |
| `src/app/icon.svg` | 브라우저 탭 아이콘(소형 변형) |
| `public/brand/mark.svg` | 앱 상단 바 로고(소형 변형, 코발트), 24px |
| `build-resources/logo-symbol.svg` | 단색 검정 원본(인쇄·반전 원본) |
| `build-resources/logo-symbol-small.svg` | 32px 이하 단색 원본 |
| `build-resources/logo-symbol-cobalt.svg` | 흰 바탕용 코발트 기본형 |

## 사용 규칙

- 색: 코발트 `#2453d6`, 반전 흰색 `#ffffff`, 단색 검정 `#111111`. 그라디언트·투명도 변형 금지.
- 여백: 앞 견본 너비(심볼 너비의 약 1/3)의 절반 이상을 사방에 둔다.
- 최소 크기: 기본형 48px, 소형 변형 16px(검증 렌더에서 부채 윤곽 유지).
- 금지: 늘이기·회전·좌우 반전, 그림자·글로우, 다른 도형 안에 넣기(앱 아이콘 타일 제외), 혼잡하거나 저대비인 배경.
- 대체 텍스트: 링크 없는 로고는 "에셋 생성기". 상단 바 로고는 이름 글자가 옆에 있어 장식(`alt=""`).
